# Super App Design System

Storybook برای پکیج `@super-app/shared` — تنها منبع UI، تم و tenant در مونوریپو.

## معماری

| لایه          | مسیر           | مسئولیت                                                    |
| ------------- | -------------- | ---------------------------------------------------------- |
| UI primitives | `src/ui/*`     | کامپوننت‌های عمومی (Radix + CVA + Tailwind v4)             |
| Theme         | `src/theme/*`  | `ThemeProvider`، `defaultTheme`، `applyTheme` و انیمیشن‌ها |
| Tenant        | `src/tenant/*` | تنظیمات tenant که تم را تأمین می‌کند                       |
| Lib           | `src/lib/*`    | `cn` و ابزارهای مشترک                                      |

هر کامپوننت در پوشهٔ خودش با الگوی زیر نوشته شده است:

```text
button/
├── Button.tsx          # پیاده‌سازی
├── Button.types.ts     # props (+ VariantProps)
├── buttonVariants.ts   # class-variance-authority
└── index.ts
```

## قرارداد استوری‌ها

- استوری‌ها در `packages/shared/stories` هستند (بیرون از `src`) تا وارد خروجی `tsc -b` که اپ‌ها مصرف می‌کنند نشوند.
- ساختار پوشه‌ها مثل `src/ui` است: `stories/ui/<Component>.stories.tsx`.
- عنوان‌ها: `Foundations/*` برای توکن‌ها و `UI/<Category>/<Component>` برای کامپوننت‌ها.
- فقط کامپوننت‌های `@super-app/shared` استفاده شوند؛ منطق دامنه (Domain) در استوری‌ها جایی ندارد.
- نوار ابزار بالا: **Theme** (Light/Dark از طریق همان `ThemeProvider` واقعی) و **Direction** (پیش‌فرض RTL).

## اجرا

```bash
pnpm install
pnpm --filter @super-app/shared storybook        # http://localhost:6006
pnpm --filter @super-app/shared build-storybook  # خروجی: packages/shared/storybook-static
```
